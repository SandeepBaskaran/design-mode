The normal variable face supports weight 100–900. The panel uses its existing sizes and weights, including its 13px base; code/preformatted snippets retain system monospace so code remains distinguishable. All ordinary labels, values, buttons, inputs, selects and textareas inherit Inter.

The existing extension asset copy includes this directory in `dist/assets/fonts`. The extension loads the WOFF2 from its own packaged origin, never Google Fonts or another remote font server. This adds no runtime network request to an external party, no collection, no permission, and no web-accessible-resource exposure. No CSP relaxation or build-script change is needed.
