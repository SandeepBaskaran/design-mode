Use a background terminal job with completion notification for the whole runner in Hermes. This is not a browser-suite pass inferred from a timeout.
- **Worktree hook hazard:** a local `git restore` invoked the repository's post-checkout hook, replacing this child's `packages/extension/dist` with a symlink to the primary checkout's generated dist. The symlink was immediately detached, the child rebuilt, and **all recorded application/shared source and dist hashes matched** the tested build. No source or hook in the origin was deliberately modified. Initial build-time dist symlink ownership had not been checked, so isolation of the earlier generated-output writes cannot be attested. The runner now rejects a symlink/out-of-worktree dist; the rejection was exercised. Parent should inspect generated dist ownership before subsequent builds. Set `CHROME_BINARY` to an installed **Chrome for Testing** executable, `FIREFOX_BINARY` to Firefox, and `GECKODRIVER` to geckodriver. These are runtime environment inputs, not hardcoded child-worktree dependencies. The environment used is recorded in `current-evidence/environment.json`.

**Before building**, inspect `packages/extension/dist`: it must be a directory in the current worktree, not a shared symlink. Do not build through a shared symlink.

```sh
npm run build:extension
npm run test:extension
node --test packages/extension/tests/certification/browser-evaluators.test.cjs
npm run lint:extension
python3 packages/extension/tests/certification/current-run.py
python3 packages/extension/tests/certification/current-matrix.py
```
