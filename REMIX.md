# Remix

Projects in this section are independent experiments, forks and specialised tools built on top of Design Mode. They are not contributions to the core extension, and inclusion does not imply compatibility, endorsement or support from the Design Mode maintainers.

| **The Art Director — SuperStories** |
| :--- |
| A stripped-down Design Mode for creative-direction workflows. It keeps the tools a director uses on a live page—pointing, moving, spacing, measuring and commenting—while removing controls for setting colour, type and other style values directly. |
| Claude Code handles the styling through a local MCP handoff, while **Copy Prompt** remains available as a manual fallback. Token awareness stays underneath the workflow so the resulting instructions can follow the page’s design system. |
| The remix also adds a **Design inspect** skill button that asks Claude Code to review the page and report its findings. SuperStories publishes it as a fork of Design Mode under the original MIT licence. |
| **[Explore The Art Director →](https://superstoriesamsterdam.github.io/DesignModexSuperstoriesArtDirector/)** |

## What belongs here

A remix should build a distinct workflow, interface or product on top of Design Mode rather than propose a change to the core extension. Each entry should identify its maintainer, explain what it keeps or changes, link to a working public project and state its relationship to Design Mode clearly.
