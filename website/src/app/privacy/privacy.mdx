## The short version

Design Mode edits the page rendered in your browser and records a local change
session. Configured release builds send usage analytics to PostHog without an
in-extension Settings off-switch. Chrome and Safari have no separate in-extension opt-in. Firefox 140+ requires its optional technical-and-interaction permission;
denial or revocation does not disable editing or clipboard export. A missing or
unavailable native permission list sends nothing. Firefox 139 and earlier cannot
install or run this release. An unconfigured source build sends nothing.
Events do not include page content or edits. A fresh install selects Cloud mode,
but it does **not** contact the hosted relay until you choose **Connect to
Cloud** and create an anonymous device credential.

When you deliberately send changes to Claude, Cursor or another coding agent,
that provider processes the content under your account settings and its own
privacy terms.

A session key is based on the page origin, path and query string. Comments are
stored separately in local extension storage. Use the Changes tab to inspect,
revert or clear recorded changes.

Design Mode reads the rendered DOM, computed styles and geometry required for
features you invoke. It cannot run on browser-internal pages, extension-store
pages or other surfaces where the browser blocks extension scripts. Do not use
it to capture passwords, private form data, confidential screenshots or content
you are not authorised to share.

Component-grouped change review also performs a bounded, read-only probe for
React or Vue component names and source-file hints attached to changed elements.
These hints are used in the local review interface. Markdown export can include
detected file and line pointers, so a copied prompt can disclose them. The
structured MCP get_changes and Send report does not add that grouping context.
Production pages may omit source metadata. The grouping choice is kept only in
panel memory.

## When network traffic starts

<NetworkBoundariesDiagram />

Normal webpage and browser actions still make their own requests (loading the opened page or fetching media referenced in it). Those are browser requests to the referenced site, not uploads to Design Mode.

For Local mode, the optional guided setup previews project configuration before writing only the files you confirm; backups stay beside those files and may hold credentials belonging to other tools, so keep them uncommitted. Local feedback-round snapshots stay in process memory.

For Cloud mode, structured service logs may include an anonymous tenant identifier, message/event type, payload byte count, latency, HTTP status, and bounded error codes—never selectors, screenshots, or message payload bodies. Design Mode does not use relay traffic to train a model.

## Screenshots and agent hand-off

Screenshots are captured by the browser. Clipboard and download actions stay on
your machine. A screenshot leaves the machine only when you explicitly use an
MCP action that returns it to a connected agent. The agent provider then handles
it under that provider's terms.

Copy as Prompt writes a Markdown specification to your clipboard. Send to Agent
makes the recorded changes available to a connected MCP client. Neither action
grants Design Mode access to your repository; the coding agent must already have
that access.

## Usage analytics

Design Mode is free and MIT-licensed, with no paid version of the extension. Release builds send bounded usage analytics to PostHog without an in-extension Settings off-switch. Chrome and Safari have no separate in-extension opt-in. Firefox 140+ requires its optional technical-and-interaction permission; denial or revocation does not disable editing or clipboard export, and Firefox 139 and earlier cannot install or run this release. An unconfigured source build sends nothing.

<AnalyticsPayloadDiagram />

Events use PostHog person profiles (`$process_person_profile: true`), IP-based GeoIP enrichment (`$geoip_disable: false`), and schema version 6. Unclassified failures emit only `Unexpected operation failure` with no runtime error text, stacks, or selectors. This source does not verify the receiver's retention, deletion or billing settings. The marketing site is a separate project and is not included in these extension events.

## What designmode.app collects

The marketing and documentation site is separate from the extension.

- Inter is fetched by the build system and self-hosted by Next.js; visiting the
  deployed site does not request it from Google Fonts.
- Google Analytics is rendered only when the deployment defines
  `NEXT_PUBLIC_GA_ID`.
- When enabled, the site sends page views plus `cta_click`, `contact_click` and
  `outbound_click` events. CTA events include the store and browser label;
  contact events include the clicked `mailto:` or `tel:` target; outbound events
  include the destination URL and link text. The repository does not configure a
  custom user ID or send extension edits or MCP payloads.

Google processes Analytics traffic under its own terms. A content or tracker
blocker may prevent the script from loading without blocking the core site.

## Browser permissions

The extension requests:

- `activeTab` and `tabs` to open the editor against the current tab and respond
  to navigation;
- `scripting` to inject the inspector after you invoke the extension;
- `storage` for the data described above;
- `sidePanel` on Chromium or Firefox's sidebar integration for the editor;
- broad host access so the editor can run on sites you choose, except protected
  browser surfaces.

The extension does not modify a page until you invoke it on that tab.

## Revoking or deleting data

- Clear a change session from the Changes tab.
- Remove saved presets or comments in the extension.
- Revoke the Cloud credential from the MCP settings page before deleting it
  locally if you want the server-side token hash removed.
- Uninstall the extension to remove its browser-managed local storage.

For a security concern, follow the private disclosure process linked below
rather than posting credentials or exploit details publicly.
